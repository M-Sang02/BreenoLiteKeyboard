# Breeno Lite Keyboard

Một bàn phím Android độc lập lấy cảm hứng từ bố cục bàn phím trong APK tham khảo, nhưng không sử dụng mã, dịch vụ xác minh, backend hoặc package của Breeno/OPPO.

## Tiếng Việt
- Telex là chế độ mặc định.
- Quy tắc chính: s/f/r/x/j cho sắc/huyền/hỏi/ngã/nặng; aa/ee/oo cho â/ê/ô; aw/ow/uw cho ă/ơ/ư; dd cho đ.
- Engine được viết lại độc lập dựa trên các quy tắc công khai của UniKey, không nhúng mã nguồn UniKey.
- Có nút VI/EN để bật/tắt xử lý Telex.

## Lưu ý build
Máy tạo file này hiện không có Android SDK/Gradle cache, nên chưa thể xuất APK nhị phân trong môi trường hiện tại. Mở thư mục bằng Android Studio rồi Build > Build APK(s).
